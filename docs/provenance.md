# Sources and verification limits

The source base is [GeeeekExplorer/nano-vllm](https://github.com/GeeeekExplorer/nano-vllm) at `bb823b3e06983d71485a8e1f23715ebd87d98ef8`. Its MIT [LICENSE](../LICENSE), complete history, original author metadata and upstream remote are retained. New implementation commits identify Steven Vu. The original native attention file was moved intact, then imported lazily. The Qwen3 model, packed projection loaders and offline public entry points remain upstream-derived.

The requirements were read from the primary [Stanford CS349D MiniEngine milestones](https://github.com/stanford-mast/CS349D-miniengine/tree/main/milestones). [Milestone 1](https://github.com/stanford-mast/CS349D-miniengine/blob/main/milestones/milestone1.md) describes iteration-level batching. [Milestone 2](https://github.com/stanford-mast/CS349D-miniengine/blob/main/milestones/milestone2.md) describes fixed pages, packed prefill, compilation and graphs. [Milestone 3](https://github.com/stanford-mast/CS349D-miniengine/blob/main/milestones/milestone3.md) describes page radix caching and chunked prefill. [Milestone 4](https://github.com/stanford-mast/CS349D-miniengine/blob/main/milestones/milestone4.md) offers advanced tracks with separate quantitative acceptance criteria. No Stanford source or source from the unlicensed pageweave-serving checkout was copied.

This extension implements the serving mechanisms in the project brief. It does not implement the advanced CPU cache tier or speculative decoding tracks. It does not claim Stanford course completion, exact grader compatibility, Qwen3-8B on an L4, MMLU results, compilation speedup, or the course throughput targets.

Verified environment was Windows, Python 3.11, Torch 2.11.0+cu128, Transformers 5.20.2, safetensors 0.8.0, tokenizers 0.23.3, and tqdm 4.70.1. [requirements-verified.txt](../requirements-verified.txt) pins that tested Python package set. CUDA checks used an RTX 5080 Laptop GPU and the existing local `Qwen/Qwen3-0.6B` snapshot `c1899de289a04d12100db370d81485cdf75e47ca`. No weights or shared environments were modified.

Dependencies remain established upstream libraries. PyTorch is BSD-3-Clause, Transformers and Hugging Face tokenizers and safetensors are Apache-2.0, and tqdm is MPL-2.0 and MIT. Safetensors was already used by the upstream loader and is now declared explicitly. Native-only flash-attn and Triton are optional. This work did not add an HTTP framework or new runtime dependency. No vulnerability audit was run, and broader package versions remain outside the tested matrix.

Raw local proof remains under ignored `evidence/` after child server cleanup. `cpu-runtime.json` records deterministic tiny-model parity and HTTP requests. `cuda-runtime.json` records independent HF greedy parity, eager versus CUDA replay parity with three live lanes in bucket four, cache pressure and cancellation. `cuda-throughput.json` records a bounded synthetic sample with actual output counts. Generated local evidence, weights and temporary checkpoints are excluded from commits.

Correctness tradeoffs are explicit. Portable attention gathers paged KV into temporary dense attention operands. It does not claim a fused high-throughput paged kernel. Decode graph masks scan the configured maximum context, which favors correctness and stable graph shapes over long-context efficiency. Conservative output reservation can reduce concurrency. The HTTP adapter is a local development service with bounded resources and custom SSE events. Authentication, TLS and public deployment are outside its scope.
